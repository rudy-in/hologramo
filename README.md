# Hologramo

I created this program because my computer teacher wanted me to make a program with OpenCV and i've made it out of OpenCV strictly without using any other model to detect my facial expressions,
however it only detects my smiling face and to decorate it , i've added a holographic effect which is why i've named it hologramo.

I've not added any preview of the program for privacy reasons as it would require my face to show it however you can test it yourself by following the steps given below

## Requirements
- Git
- OpenCV , Numpy `pip install opencv numpy`
- any code editor (Neovim, Helix (which is what i've used) , VSCode etc.)

## Installation Commands

```
git clone https://github.com/rudy-in/hologramo
cd hologramo/src
```
- Running the code requires you to execute the main.py file `python3 main.py`
